MiniFlix Privacy Notice

Last updated: 24 November 2026

MiniFlix is an independent personal media-catalogue project. It is not affiliated with, endorsed by, or connected to Netflix or any other streaming service.

Information used for accounts

If you create an account, MiniFlix asks for your email address, a username and a password. Authentication is provided by Supabase. Your password is submitted to Supabase Authentication and is not intentionally stored as readable text by the MiniFlix website.

During registration, the email address is temporarily kept in your browser's local storage so it can be passed from the signup page to the registration page. The website also stores your display name locally after login for interface purposes.

Hosting and service providers

The website is hosted using Cloudflare Pages. Account authentication is handled by Supabase. These providers process technical data as needed to deliver their services; their own privacy terms also apply.

Media and external resources

Catalogue artwork and media references may be served from external locations. When your browser requests those resources, the relevant provider may receive standard connection information such as your IP address.

Choices and account questions

You can stop using the website at any time. For questions about this project or an account, contact the project maintainer through the MiniFlix GitHub repository.

About this project

MiniFlix is an independent learning and portfolio project for browsing a media catalogue. It does not represent itself as an official streaming service or as a Netflix product.
